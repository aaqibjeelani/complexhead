School password generator

Creates a new access password and the salted hash to paste into assets/js/schools.js.

Administrator tool. It cannot reveal an existing password. Never publish generated passwords, and do not leave this page open on a shared computer.

How to use:

  1. Generate a password above and copy the snippet.
  2. Open assets/js/schools.js and replace that school's access block with the snippet.
  3. Save, commit and deploy. The old password stops working immediately.
  4. Hand the new password to that school only. Give the master password to the complex head only.

Passwords are hashed with 8000 rounds of SHA-256. Only the salt and hash are stored in the published site.
